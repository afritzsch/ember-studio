# User requests — 2026-11-19

Raw requests, as given to the lead:

> an ableton-like browser, the one we have is barely working. rightclick (two finger tap) on the track list must show a popup where i can choose between create an audio or midi track. when i click on the timeline on a midi track i want to create a midi region

## Findings
- The browser pane was never specified: `ProjectWindowView` shows a `PanePlaceholder("Browser")`. There is also no way to bring an audio file into a project from the app UI; only `ImportAsset` over the control socket/MCP does it.
- The track header column has no context menu. ⌘T/⇧⌘T (UI-002) already add tracks.
- A single click on empty canvas deselects and starts a marquee (UI-013), so clip creation needs its own gesture.

## Answers (user, 2026-11-19)
| Question | Answer |
|---|---|
| Browser scope for the first version | All four: files + drag to timeline, preview while browsing, instruments & effects, favorites/collections |
| Gesture that creates a MIDI clip | Double-click on empty space of a MIDI track (single click keeps deselect/marquee); also "Insert MIDI Clip" in the canvas context menu |
| New MIDI clip length | 1 bar (the time signature at that position), starting at the snapped click |
| Priority | After T-111 and T-112 (correctness fixes), before the other follow-ups and refactors |
