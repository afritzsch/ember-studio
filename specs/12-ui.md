# 12 — User Interface

**Depends on:** 07 (ProjectStore, Commands), 08 (EngineClient for meters/telemetry) · **Owns:** `App/EmberStudio/`.

SwiftUI shell, with custom AppKit `NSView`s backed by CALayer/Metal for dense canvases (D-17). The UI mutates only through `ProjectStore.perform` and gestures (MODEL-003). It never talks to the engine directly, except for read-only meters/telemetry and plugin views.

## Layout
```
┌ Toolbar: transport · tempo/sig · position (bars|time) · CPU/xrun · record/loop/metronome ┐
├ Browser (files, plugins) │ Arrange (track headers | timeline canvas) │ Inspector (track/clip/device) ┤
└ Bottom pane (tabs): Mixer · Piano Roll · Device chain · Comp editor ┘
```
